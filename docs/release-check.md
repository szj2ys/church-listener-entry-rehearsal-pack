# Before distributing the listener card

Use this with the completed handoff, card and latest rehearsal rows. A role can own a task; personal names and contact details do not belong in a public example.

- [ ] Every bracketed instruction in the working card is replaced or removed. No `.invalid` example address remains.
- [ ] The operator confirms the current public listener destination, support window and actual language offer.
- [ ] The digital text link and printed typed address reach that same service on the intended connection.
- [ ] A permitted test passage arrives. Audio is advertised only when separately tested and available for the selected language.
- [ ] A competent reader reviews any translated card wording and the relevant language variety. Automated draft text alone is not that review.
- [ ] The printed version is readable at its real size. The digital copy has selectable text and a descriptive link; the visitor is not required to scan an image.
- [ ] The help location is specific, its helper is assigned, and the fallback is physically or operationally available.
- [ ] All failures that affect the advertised offer have a passing retest or the unsupported offer has been removed. `NOT TESTED` is not a pass.
- [ ] The current date/version appears on the card. Stale printed copies, bulletin links and screen destinations are replaced together.
- [ ] Completed logs and operator records are stored privately, without credentials or unnecessary participant data.
